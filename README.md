# Easylexia Site

Sitio estático de presentación, soporte y condiciones de Easylexia. Pensado para publicarse gratis con GitHub Pages.

## Activar GitHub Pages

1. Abre **Settings → Pages** en el repositorio `mikelju-dev/easylexia-site`.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
4. Espera a que GitHub publique el sitio. La URL esperada es `https://mikelju-dev.github.io/easylexia-site/`.
5. Abre y prueba la página principal, ayuda, privacidad y términos mediante HTTPS.

## Antes de enviar Easylexia al directorio público

- Revisa `privacidad-REVISION-ANTES-DE-PUBLICAR.md` y confirma los datos reales de procesamiento.
- Añade un canal de contacto que puedas atender y que estés dispuesto a publicar.
- Quita la indicación de borrador en la política de privacidad cuando esté verificada.
- Actualiza los enlaces públicos del formulario de envío del plugin con las páginas publicadas.
- Verifica el desarrollador y el nombre público en la configuración/paquete del plugin (ahora el manifiesto todavía menciona Biar Technology).

Este repositorio contiene páginas del sitio; no contiene el código ni las instrucciones privadas del plugin Easylexia.
